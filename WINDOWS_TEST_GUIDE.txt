Eye God - Windows 환경 테스트 가이드
(작성일: 2026-09-09, GitHub 저장소 기준으로 재작성)

이 프로젝트는 이제 git 저장소로 관리됩니다 (https://github.com/StarBlossom99/Eye-God,
private repo). 압축파일을 따로 주고받지 않고, 아래 순서대로 git으로 직접 받아서
테스트하면 됩니다. 나중에 코드가 업데이트되면 압축파일을 다시 받을 필요 없이
git pull 한 번이면 최신 상태로 맞출 수 있습니다.

===========================================
0. 저장소에 들어있는 것 / 안 들어있는 것
===========================================

git에 포함되어 관리되는 것:
- src/, web/, models/face_landmarker.task, requirements.txt, .env.example,
  .python-version, CLAUDE.md, rhythm_game.txt, doc/ (설계 문서)

git에서 의도적으로 제외되는 것 (.gitignore, 직접 준비해야 함):
- 파이썬 가상환경(eye/) - macOS 전용 패키지가 섞여있어서 공유 대상이 아님.
  Windows에서 새로 만들어야 함 (아래 3번 참고).
- .env - 비밀키가 들어있는 파일. .env.example을 복사해서 새로 만들어야 함
  (아래 5번 참고).
- data/ 안의 calibration.json, eyegod.db - 실행하면 자동 생성됨.

===========================================
1. 저장소 접근 권한
===========================================

private 저장소라서 GitHub 계정이 저장소에 collaborator로 초대되어 있어야
git clone이 됩니다. 초대 안 됐다면 저장소 관리자(StarBlossom99)에게 GitHub
아이디를 알려주고 초대를 받으세요 (초대 메일의 링크를 눌러 수락해야 함).

===========================================
2. 사전 준비 (프로그램 설치)
===========================================

- Git for Windows 설치: https://git-scm.com/download/win
  (설치 옵션은 기본값 그대로 진행하면 됨)
- Python 3.12.x 설치 (python.org에서 다운로드). 설치 중 "Add python.exe to PATH"
  체크박스 꼭 체크할 것.

===========================================
3. 프로젝트 받기 (git clone)
===========================================

원하는 폴더에서 명령 프롬프트(cmd) 또는 PowerShell을 열고:

    cd C:\
    git clone https://github.com/StarBlossom99/Eye-God.git eyegod
    cd eyegod

private 저장소라 처음 clone할 때 GitHub 로그인 창이 브라우저로 뜹니다 -
그 창에서 본인 GitHub 계정으로 로그인/승인하면 됩니다 (Git for Windows에
기본 포함된 Git Credential Manager가 처리 - 별도 설치 불필요).

이후 코드가 업데이트되면, 같은 폴더에서:

    git pull

만 실행하면 최신 상태로 맞춰집니다.

디자인 작업처럼 본인이 파일을 직접 수정할 계획이라면, main 브랜치에 바로
작업하지 말고 본인 이름으로 브랜치를 하나 만들어서 작업하는 걸 권장합니다
(다른 사람 작업과 충돌 방지):

    git checkout -b 본인이름-design

===========================================
4. 가상환경 만들기
===========================================

    python -m venv eye

가상환경 활성화:
- cmd:        eye\Scripts\activate
- PowerShell: eye\Scripts\Activate.ps1

PowerShell에서 "이 시스템에서 스크립트를 실행할 수 없습니다" 오류가 나면:

    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

실행 후 다시 Activate.ps1을 시도.

===========================================
5. 패키지 설치
===========================================

가상환경이 활성화된 상태(프롬프트 앞에 (eye) 표시)에서:

    pip install -r requirements.txt

requirements.txt는 sys_platform 조건이 걸려있어서 Windows에서는 자동으로
screeninfo만 설치되고 macOS 전용 pyobjc 패키지들은 건너뜁니다 - 별도로 손댈 것
없음.

===========================================
6. .env 파일 만들기
===========================================

    copy .env.example .env

.env 파일을 열어서 채워야 할 값:

(1) SESSION_SECRET_KEY - 필수, 없으면 서버 자체가 안 뜸. 직접 생성:

    python -c "import secrets; print(secrets.token_hex(32))"

로 나온 값을 SESSION_SECRET_KEY=에 붙여넣기.

(2) GOOGLE_CLIENT_ID / GOOGLE_CLIENT_SECRET, KAKAO_CLIENT_ID / KAKAO_CLIENT_SECRET
    - 로그인 기능(및 로그인 뒤에 있는 게임/마이페이지/병원찾기/사진분석 전부)을
    테스트하려면 필요합니다. 카카오도 이제 실제 OAuth라 예전처럼 키 없이
    테스트할 수 있는 mock 로그인이 없습니다.
    저장소 관리자(StarBlossom99)에게 이 4개 값을 안전한 방법으로(깃허브/문서에
    올리지 말고 개인 메시지 등으로) 전달받아서 채워 넣으세요.
    - Google: 로그인하려는 본인 Google 계정이 Google Cloud Console의 OAuth
      동의 화면 > Test users에 등록되어 있어야 합니다. 안 되어 있으면
      관리자에게 본인 이메일을 알려주고 추가를 요청하세요.
    - Kakao: 보통은 별도 등록 없이 아무 카카오 계정으로나 로그인이 됩니다.
      만약 로그인이 막히면 관리자에게 알려주세요 (카카오 개발자 콘솔의
      "팀 관리"에 멤버로 추가가 필요할 수 있습니다).

(3) 나머지 키(NAVER_MAP_CLIENT_ID/SECRET, HIRA_API_KEY)는 없어도 서버는
    정상적으로 뜹니다 - 해당 기능만 비활성화되거나 mock 데이터로 동작합니다:
    - HIRA_API_KEY 없음 -> 안과 목록이 가짜(mock) 데이터로 표시됨
    - NAVER_MAP_CLIENT_ID 없음 -> 지도가 안 뜨고 목록만 표시됨
    - NAVER_MAP_CLIENT_SECRET 없음 -> 지역 검색이 503 에러로 실패 (검색창 외
      기능은 정상)

===========================================
7. 실행 - CLI/데스크톱 모드
===========================================

반드시 프로젝트 루트(clone한 폴더)에서 실행할 것 (models/, data/ 경로가
실행 위치 기준 상대경로임):

    (가상환경 활성화된 상태에서)

    # 1단계: 캘리브레이션 (화면에 9개 점이 순서대로 뜨고, 각 점을 보고 있으면
    # 캘리브레이션 데이터가 저장됨. q로 중단 가능)
    python src\main.py --calibrate

    # 2단계: 시선추적 게임 실행 (1단계의 data\calibration.json 사용)
    python src\main.py

    # 눈 깜빡임 모니터링만 콘솔에 출력
    python src\main.py --blink

Windows에서 처음 웹캠에 접근하면 "카메라 접근을 허용하시겠습니까" 같은
시스템 권한 팝업이 뜰 수 있음 - 허용 필요.

===========================================
8. 실행 - 웹 모드 (브라우저)
===========================================

    uvicorn web.backend.app:app --reload

콘솔에 뜨는 주소로 접속하되, 반드시 http://localhost:8000 으로 접속할 것
(127.0.0.1로 접속하면 Google/Kakao 로그인의 redirect_uri가 안 맞아서 로그인
실패함 - 다른 기능은 상관없음).

브라우저는 크롬 권장 (Chrome/Edge). 눈 깜빡임 모니터링은 Chromium 계열
브라우저에서 Web Worker 기반으로 동작하도록 구현되어 있고, Firefox 등에서는
자동으로 기존 방식(메인 스레드)으로 대체되어 동작합니다 - 어느 브라우저를 써도
기능 자체는 동작함.

===========================================
9. 정상 작동해야 하는 기능 / 안 돼도 문제없는 기능
===========================================

(SESSION_SECRET_KEY + Google/Kakao 키를 채운 상태 기준. Google/Kakao 키를
하나도 채우지 않으면 로그인 자체가 안 되어 아래 "로그인 필요" 기능 전부
테스트 불가능합니다.)

정상 작동해야 하는 기능:
- CLI 모드 전체 (캘리브레이션/게임/blink) - 웹캠만 있으면 됨, API 키 무관
- 웹 서버 구동 (uvicorn) - SESSION_SECRET_KEY만 있으면 뜸
- Google 로그인 / Kakao 로그인 / 로그아웃 (둘 중 하나라도 키가 채워져 있으면 됨)
- 로그인 게이트 통과 (game/hospitals/mypage/analysis 접근)
- 시선추적 미니게임 (캘리브레이션→게임→결과, 로그인 계정별 DB 저장까지)
- 리듬게임
- 눈 깜빡임 모니터링 (홈 화면 토글, Worker 기반 캡처, 최근 1분 카운트,
  1분에 5회 이하일 때 배너+알림 팝업)
- 안약 알림 타이머 (시작/중지 버튼, 지정한 주기마다 배너+알림 팝업)
- 마이페이지 (최근 로그인/게임 점수 표시)
- 홈 화면 건강 요약 2x2 카드
- 안과 목록 (mock 데이터로 - HIRA 키 없으면 가짜 병원 5곳이 뜨지만 목록 자체는 정상)
- 위치 정보 동의(geolocation) - 브라우저 기능이라 API 키 무관
- analysis.html (사진 선택/미리보기 + "준비 중" 메시지)

작동 안 해도 문제없는 기능 (API 키가 없어서 나타나는 정상적인 결과 - 버그 아님):
- Google 또는 Kakao 로그인 버튼 (해당 provider 키가 비어있는 경우) - 눌러도
  에러. 다른 provider로 로그인하면 됨. 둘 다 비어있으면 로그인 자체가
  전부 안 됨 (설계상 정상 - 6번 항목 참고)
- 안과 지도 렌더링 - NAVER_MAP_CLIENT_ID 없음 -> 지도는 안 뜨고 목록만 표시
- 실제 병원 데이터 - HIRA_API_KEY 없음 -> mock 데이터로 대체 표시
- 지역명 검색 (홈 헤더/지도/hospitals.html 3곳 전부) - NAVER_MAP_CLIENT_SECRET
  없음 -> 503, "찾을 수 없습니다" 메시지
- 백내장 위험도 / 충혈도 - API 키와 무관, 애초에 실제 분석 모델이 없어서
  항상 "측정 미완료"로 표시됨 (정상)
- 눈 깜빡임 알림의 OS 팝업 - 브라우저 알림 권한을 허용 안 했거나, 이전에
  거부한 적 있으면 안 뜸 (배너는 항상 뜸). 브라우저 사이트 설정에서 알림
  권한을 "허용"으로 바꾸면 해결됨

===========================================
10. Windows 관련 참고사항
===========================================

- src/screen.py는 OS별로 화면 크기를 다르게 가져옵니다 - macOS는 AppKit,
  Windows는 screeninfo 패키지. requirements.txt 설치만 정상적으로 됐다면
  자동으로 맞는 방식이 사용되므로 별도 설정 불필요. (웹 모드는 브라우저
  뷰포트 크기를 쓰므로 이 부분과 무관함)
- 방화벽/백신 프로그램이 처음 실행 시 "이 앱이 네트워크에 접근하려고 합니다"
  같은 팝업을 띄울 수 있음 (uvicorn 서버가 로컬 포트를 여는 것에 대한 정상적인
  경고) - 허용 필요.
- 웹캠이 여러 대(내장+외장 등)면 OpenCV가 기본으로 잡는 카메라(index 0)가
  원하는 카메라가 아닐 수 있음 - 그 경우 src/main.py의 cv2.VideoCapture(0)
  호출부의 0을 1, 2 등으로 바꿔서 테스트.

===========================================
문제가 생기면
===========================================

- "ModuleNotFoundError" -> 가상환경이 활성화된 상태인지 확인 (프롬프트 앞에
  (eye) 표시가 있어야 함), pip install -r requirements.txt 다시 실행.
- 서버가 "SESSION_SECRET_KEY" 관련 에러로 안 뜸 -> .env 파일에 그 값이 비어있는
  것. 6번 단계 다시 확인.
- 로그인 버튼을 눌러도 아무 반응이 없거나 에러 -> .env에 해당 provider의
  키가 비어있지 않은지, http://localhost:8000 으로 접속했는지(127.0.0.1 아님)
  확인.
- 웹캠 화면이 안 뜸 -> 브라우저 주소창 왼쪽 카메라 아이콘에서 권한 허용
  여부 확인, 다른 프로그램(Zoom, Teams 등)이 카메라를 이미 점유하고 있지
  않은지 확인.
- git clone/pull이 인증 오류로 실패 -> 저장소에 collaborator로 초대되어
  있는지, 초대 메일을 수락했는지 확인.
