Eye God - Windows 환경 테스트 가이드
(작성일: 2026-09-08)

이 프로젝트는 git 저장소가 아니라서 압축 파일(EyeGod_source.zip)로 소스코드를
전달합니다. 아래 순서대로 진행하면 Windows PC에서도 동일하게 테스트할 수 있습니다.

===========================================
0. 압축 파일에 들어있는 것 / 안 들어있는 것
===========================================

포함:
- src/, web/, models/face_landmarker.task, requirements.txt, .env.example,
  .python-version, CLAUDE.md, rhythm_game.txt

포함 안 됨 (직접 준비해야 함):
- 파이썬 가상환경(eye/) - macOS 전용 패키지가 섞여있어서 그대로 옮기면 안 됨.
  Windows에서 새로 만들어야 함 (아래 2번 참고).
- .env - 비밀키가 들어있는 파일이라 원래도 배포/공유하지 않음. .env.example을
  복사해서 새로 만들어야 함 (아래 4번 참고).
- data/ 안의 calibration.json, eyegod.db - 실행하면 자동 생성됨.

===========================================
1. 사전 준비
===========================================

- Python 3.12.x 설치 (python.org에서 다운로드). 설치 중 "Add python.exe to PATH"
  체크박스 꼭 체크할 것.
- 압축 파일을 원하는 폴더에 풀기 (예: C:\eyegod\).

===========================================
2. 가상환경 만들기
===========================================

압축 푼 폴더에서 명령 프롬프트(cmd) 또는 PowerShell을 열고:

    cd C:\eyegod
    python -m venv eye

가상환경 활성화:
- cmd:        eye\Scripts\activate
- PowerShell: eye\Scripts\Activate.ps1

PowerShell에서 "이 시스템에서 스크립트를 실행할 수 없습니다" 오류가 나면:

    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

실행 후 다시 Activate.ps1을 시도.

===========================================
3. 패키지 설치
===========================================

가상환경이 활성화된 상태(프롬프트 앞에 (eye) 표시)에서:

    pip install -r requirements.txt

requirements.txt는 sys_platform 조건이 걸려있어서 Windows에서는 자동으로
screeninfo만 설치되고 macOS 전용 pyobjc 패키지들은 건너뜁니다 - 별도로 손댈 것
없음.

===========================================
4. .env 파일 만들기
===========================================

    copy .env.example .env

.env 파일을 열어서 SESSION_SECRET_KEY는 반드시 채워야 서버가 뜹니다 (다른 키
없이는 안 뜨는 유일한 값):

    python -c "import secrets; print(secrets.token_hex(32))"

로 나온 값을 SESSION_SECRET_KEY=에 붙여넣기.

나머지 키(NAVER_MAP_CLIENT_ID/SECRET, HIRA_API_KEY, GOOGLE_CLIENT_ID/SECRET)는
없어도 서버는 정상적으로 뜹니다 - 해당 기능만 비활성화되거나 mock 데이터로
동작합니다:
- HIRA_API_KEY 없음 -> 안과 목록이 가짜(mock) 데이터로 표시됨
- NAVER_MAP_CLIENT_ID 없음 -> 지도가 안 뜨고 목록만 표시됨
- NAVER_MAP_CLIENT_SECRET 없음 -> 지역 검색이 503 에러로 실패 (검색창 외 기능은 정상)
- GOOGLE_CLIENT_ID/SECRET 없음 -> 구글 로그인 버튼이 깨짐. 로그인 자체는
  "카카오로 계속하기"(mock 로그인, 실제 API 키 불필요)로 테스트 가능하므로,
  로그인 이후 화면(게임/마이페이지 등)을 테스트하려면 이 방법을 쓰면 됨.

즉 시선추적 게임/리듬게임/눈 깜빡임 모니터링 같은 핵심 기능만 테스트하려면
SESSION_SECRET_KEY만 채우고 나머지는 비워둬도 충분합니다.

===========================================
5. 실행 - CLI/데스크톱 모드
===========================================

반드시 프로젝트 루트(압축 푼 폴더)에서 실행할 것 (models/, data/ 경로가
실행 위치 기준 상대경로임):

    (가상환경 활성화된 상태에서)

    # 1단계: 캘리브레이션 (화면에 9개 점이 순서대로 뜨고, 각 점을 보고 있으면
    # 캘리브레이션 데이터가 저장됨. q로 중단 가능)
    python src\main.py --calibrate

    # 2단계: 시선추적 게임 실행 (1단계의 data\calibration.json 사용)
    python src\main.py

    # 눈 깜빡임 모니터링만 콘솔에 출력
    python src\main.py --blink

Windows에서 처음 웹캠에 접근하면 "카메라 접근을 허용하시겠습니까" 같은
시스템 권한 팝업이 뜰 수 있음 - 허용 필요.

===========================================
6. 실행 - 웹 모드 (브라우저)
===========================================

    uvicorn web.backend.app:app --reload

콘솔에 뜨는 주소로 접속하되, 반드시 http://localhost:8000 으로 접속할 것
(127.0.0.1로 접속하면 구글 로그인의 redirect_uri가 안 맞아서 로그인 실패함 -
다른 기능은 상관없음).

브라우저는 크롬 권장 (Chrome/Edge). 눈 깜빡임 모니터링은 Chromium 계열
브라우저에서 Web Worker 기반으로 동작하도록 구현되어 있고, Firefox 등에서는
자동으로 기존 방식(메인 스레드)으로 대체되어 동작합니다 - 어느 브라우저를 써도
기능 자체는 동작함.

===========================================
7. 이 압축 파일 기준으로 정상 작동해야 하는 기능 / 안 돼도 문제없는 기능
===========================================

(SESSION_SECRET_KEY만 채우고 나머지 키는 비워둔 상태 기준)

정상 작동해야 하는 기능:
- CLI 모드 전체 (캘리브레이션/게임/blink) - 웹캠만 있으면 됨, API 키 무관
- 웹 서버 구동 (uvicorn) - SESSION_SECRET_KEY만 있으면 뜸
- 카카오 로그인(mock) / 로그아웃 - 실제 OAuth 아니라 API 키 불필요
- 로그인 게이트 통과 (game/hospitals/mypage/analysis 접근)
- 시선추적 미니게임 (캘리브레이션→게임→결과, DB 저장까지)
- 리듬게임
- 눈 깜빡임 모니터링 (홈 화면 토글, Worker 기반 캡처 포함)
- 마이페이지 (최근 로그인/게임 점수 표시)
- 홈 화면 건강 요약 2x2 카드
- 안과 목록 (mock 데이터로 - HIRA 키 없으면 가짜 병원 5곳이 뜨지만 목록 자체는 정상)
- 위치 정보 동의(geolocation) - 브라우저 기능이라 API 키 무관
- analysis.html (사진 선택/미리보기 + "준비 중" 메시지)

작동 안 해도 문제없는 기능 (API 키가 없어서 나타나는 정상적인 결과 - 버그 아님):
- 구글 로그인 버튼 - GOOGLE_CLIENT_ID/SECRET 없음 -> 버튼 눌러도 에러.
  카카오로 대체 테스트하면 됨
- 안과 지도 렌더링 - NAVER_MAP_CLIENT_ID 없음 -> 지도는 안 뜨고 목록만 표시
- 실제 병원 데이터 - HIRA_API_KEY 없음 -> mock 데이터로 대체 표시
- 지역명 검색 (홈 헤더/지도/hospitals.html 3곳 전부) - NAVER_MAP_CLIENT_SECRET
  없음 -> 503, "찾을 수 없습니다" 메시지
- 백내장 위험도 / 충혈도 - API 키와 무관, 애초에 실제 분석 모델이 없어서
  항상 "측정 미완료"로 표시됨 (정상)

한 줄 요약: CLI 전체 + 카카오 로그인 경유한 웹 서비스 핵심 기능(게임 2종,
눈 깜빡임 모니터링, 마이페이지)은 전부 정상 테스트 가능하고, 구글 로그인/
실제 지도/실제 병원 데이터/지역 검색은 키가 없어서 의도적으로 비활성화되는
것이니 이 부분이 안 되더라도 버그로 보고할 필요 없음.

===========================================
8. Windows 관련 참고사항
===========================================

- src/screen.py는 OS별로 화면 크기를 다르게 가져옵니다 - macOS는 AppKit,
  Windows는 screeninfo 패키지. requirements.txt 설치만 정상적으로 됐다면
  자동으로 맞는 방식이 사용되므로 별도 설정 불필요. (웹 모드는 브라우저
  뷰포트 크기를 쓰므로 이 부분과 무관함)
- 방화벽/백신 프로그램이 처음 실행 시 "이 앱이 네트워크에 접근하려고 합니다"
  같은 팝업을 띄울 수 있음 (uvicorn 서버가 로컬 포트를 여는 것에 대한 정상적인
  경고) - 허용 필요.
- 웹캠이 여러 대(내장+외장 등)면 OpenCV가 기본으로 잡는 카메라(index 0)가
  원하는 카메라가 아닐 수 있음 - 그 경우 src/main.py의 cv2.VideoCapture(0)
  호출부의 0을 1, 2 등으로 바꿔서 테스트.

===========================================
문제가 생기면
===========================================

- "ModuleNotFoundError" -> 가상환경이 활성화된 상태인지 확인 (프롬프트 앞에
  (eye) 표시가 있어야 함), pip install -r requirements.txt 다시 실행.
- 서버가 "SESSION_SECRET_KEY" 관련 에러로 안 뜸 -> .env 파일에 그 값이 비어있는
  것. 4번 단계 다시 확인.
- 웹캠 화면이 안 뜸 -> 브라우저 주소창 왼쪽 카메라 아이콘에서 권한 허용
  여부 확인, 다른 프로그램(Zoom, Teams 등)이 카메라를 이미 점유하고 있지
  않은지 확인.
