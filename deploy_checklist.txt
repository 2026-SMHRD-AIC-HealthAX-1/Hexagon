Eye God - 실 배포 전 체크리스트
(작성일: 2026-09-08 / 현재 상태: 로컬 개발, http://localhost:8000, git 저장소 아님)

===========================================
1. 반드시 바꿔야 하는 코드/설정
===========================================

[ ] web/backend/app.py - SessionMiddleware(https_only=False) -> https_only=True
    이유: HTTPS가 아니면 세션 쿠키 자체가 전송되지 않아 로그인이 깨짐.
    지금은 localhost라 False로 두고 있는 상태 (CLAUDE.md에도 명시됨).

[ ] Google Cloud Console > OAuth 클라이언트 > 승인된 리디렉션 URI
    실 도메인 URI 추가: https://실도메인/api/auth/google/callback
    (localhost용 URI는 남겨두고 "추가"하는 형태 - 로컬 개발도 계속 되게)
    코드의 request.url_for("google_callback")가 접속 도메인을 그대로 따라가므로
    콘솔 등록만 해주면 코드 수정은 필요 없음.

[ ] NCP 콘솔 > 해당 Maps 애플리케이션 > 서비스 URL
    실 도메인 추가 등록 (Maps JS SDK + Geocoding 둘 다 여기 걸림).
    안 하면 지도 스크립트 로드/place-search가 인증 실패로 죽음.

[ ] .env 운영 방식
    .env 파일 자체를 서버에 올리기보다, 호스팅 플랫폼의 환경변수 설정으로
    옮기거나 서버에만 두고 권한을 제한. 코드 변경 불필요, 운영 방식만 변경.

[ ] uvicorn 실행 방식
    --reload 제거 (개발용 옵션).
    gunicorn -k uvicorn.workers.UvicornWorker 같은 프로세스 매니저,
    또는 최소 systemd/supervisor로 프로세스 재시작 관리 필요.

===========================================
2. HTTPS가 필수인 이유
===========================================

- getUserMedia (웹캠): localhost는 예외지만 실 도메인은 HTTPS 없으면
  브라우저가 카메라 접근 자체를 막음.
- navigator.geolocation: 마찬가지로 secure context 필요.
- 세션 쿠키: 위 https_only=True와 직결.

=> 도메인 + TLS 인증서(Let's Encrypt 등)가 배포의 최소 전제조건.
   보통 nginx/Caddy로 TLS 종료 후 uvicorn으로 리버스 프록시하는 구조.

===========================================
3. 지금 구조에서 걸릴 수 있는 것들
===========================================

[ ] SQLite 파일 (data/eyegod.db)
    컨테이너/서버리스처럼 파일시스템이 휘발성인 환경에 배포하면
    재시작마다 DB가 날아감. 영구 디스크가 있는 호스팅(VM 또는 볼륨 마운트)
    필요. 백업 전략도 현재 없음 - 최소 주기적 파일 복사 정도는 필요.

[ ] MediaPipe 동기 처리 (web/backend/sessions/*)
    WebSocket 핸들러가 async 안에서 MediaPipe를 동기로 돌림 -
    "로컬 단일 사용자" 전제로 설계된 부분. 동시 접속자가 여러 명이면
    한 명의 프레임 처리가 다른 연결의 이벤트 루프를 막음.
    여러 명이 동시에 쓸 걸 예상하면 run_in_executor로 옮기는 작업 필요.
    (지금 당장은 선택 사항, "배포"가 다중 사용자를 뜻하면 우선순위 올라감)

[ ] requirements.txt 불완전
    pyobjc-*, screeninfo 누락 - 그대로는 새 서버에서 설치 안 될 수 있음.
    배포 서버는 보통 Linux라 pyobjc-*(macOS 전용)는 애초에 설치 대상 아니지만,
    웹 서비스 실행에 실제로 필요한 패키지 기준으로 다시 정리하는 게 안전.

[ ] git 저장소 아님
    배포 파이프라인(CI/CD, 롤백)을 쓰려면 최소한 git init 필요.

===========================================
4. 외부 API 요금/제한
===========================================

[ ] HIRA API, NCP Maps/Geocoding 모두 호출량 제한/요금제 존재.

    배포 전에 각 API의 일일/월간 호출 한도 확인.
