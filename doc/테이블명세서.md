# 테이블 명세서

**과제명 :** Eye God — 안구 건조증 기반 백내장 위험 조기 예측 서비스
**작성일 :** 2026. 09. 08. (2026. 09. 09. MySQL 전환 반영)

> 실제 구현 DB는 MySQL입니다 (`web/backend/db.py`, `PyMySQL` 드라이버, ORM 미사용). 아래 스키마와
> CREATE TABLE 스크립트는 실제 코드와 동일합니다. 날짜/시각 컬럼은 실제 DATETIME/TIMESTAMP
> 타입이 아니라 ISO8601 문자열을 `VARCHAR(64)`에 그대로 저장합니다 — 문자열로도 시간순 정렬이
> 정확히 되기 때문에(ISO8601의 특성) 굳이 DB의 날짜 타입/타임존 변환 기능을 쓰지 않았습니다.

|---|---|---|

**Table 생성 스크립트** (MySQL 8+)
```sql
CREATE TABLE users (
    id              BIGINT AUTO_INCREMENT PRIMARY KEY,
    provider        VARCHAR(20) NOT NULL CHECK (provider IN ('google', 'kakao')),
    created_at      VARCHAR(64) NOT NULL,
    last_login_at   VARCHAR(64) NOT NULL,
    google_sub      VARCHAR(255) UNIQUE,
    kakao_id        VARCHAR(255) UNIQUE,
    email           VARCHAR(255)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

```sql

    id          BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id     BIGINT NOT NULL,
    game_type   VARCHAR(20) NOT NULL DEFAULT 'gaze' CHECK (game_type IN ('gaze', 'rhythm')),
    score       INT NOT NULL,
    played_at   VARCHAR(64) NOT NULL,
    FOREIGN KEY (user_id) REFERENCES users(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```
